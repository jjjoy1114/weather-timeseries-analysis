# 창원 기온 시계열 분석 (2023~2025 + 장기 1996~2025)

창원 지역의 일별 평균기온(2023-01-01 ~ 2025-12-31, 1,096일)을 분석한 시계열 데이터 분석 프로젝트입니다. 이동평균·변화율·월별 집계로 계절성과 변동성을 살펴보았고, 평가 피드백을 반영해 기간을 30년(1996~2025, 10,958일)으로 늘려 장기 추세를 확인했습니다.

> **보너스 과제 수행**: ① 분석 결과 대시보드(Streamlit, `app.py`)와 ② 시계열 분해(추세/계절성/잔차)를 모두 수행했습니다.

## 분석 질문

1. 연평균 기온이 2023 → 2025 사이 오르는 추세가 있는가?
2. 월별 기온 패턴은 어떻게 반복되며, 가장 덥고 추운 달은 언제인가?
3. 하루 사이 기온 변동이 가장 큰 시기는 언제인가?
4. 기간을 30년(1996~2025)으로 늘리면 장기 추세가 보이는가? (평가 피드백 반영)

## 실행 방법

1. Python 3.10 이상 설치 (실제 실행 환경: Python 3.13, Windows + VS Code)
2. 필요 라이브러리 설치:
   ```
   pip install -r requirements.txt
   ```
3. `analysis.ipynb`(1차 분석, 2023~2025)를 열어 위에서부터 순서대로 셀을 실행
4. `notebooks/02_장기추세_30년.ipynb`(장기 추세)를 위에서부터 순서대로 실행 — 처음 실행 시 30년 데이터를 받아 `data/`에 저장
5. 대시보드: 터미널에서 `streamlit run app.py` → 브라우저에서 `http://localhost:8501`

## 데이터 출처

- Open-Meteo Historical Weather API (archive-api.open-meteo.com)
- 지역: 창원 (위도 35.23, 경도 128.68)
- 라이선스: CC BY 4.0 — "Weather data by Open-Meteo.com"

## 분석 결과 요약

- 창원 기온은 8월(약 27.6°C) 최고, 1월(약 2.1°C) 최저의 뚜렷한 계절성을 보인다.
- 연평균은 2024년(15.42°C)이 가장 높았으나, 3년만으로는 일관된 추세로 보기 어렵다.
- 30년(1996~2025)으로 늘리면 10년당 +0.25°C의 완만한 상승 경향이 보이며, 2023~2025는 30년 중 가장 따뜻한 3년이다. (평가 피드백 반영, `notebooks/02_장기추세_30년.ipynb`)
- 하루 사이 기온 급락은 11~1월에 집중되며, 겨울의 하루 평균 변동폭은 여름의 약 2.6배다.
