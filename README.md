# 창원 기온 시계열 분석 (2023~2025)

창원 지역의 일별 평균기온(2023-01-01 ~ 2025-12-31, 약 1,096일)을 분석한 시계열 데이터 분석 프로젝트입니다. 이동평균·변화율·월별 집계로 계절성과 변동성을 살펴보고, 보너스로 시계열 분해(추세/계절성/잔차)를 수행했습니다.

## 분석 질문

1. 연평균 기온이 2023 → 2025 사이 오르는 추세가 있는가?
2. 월별 기온 패턴은 어떻게 반복되며, 가장 덥고 추운 달은 언제인가?
3. 하루 사이 기온 변동이 가장 큰 시기는 언제인가?

## 폴더 구조

```
weather-timeseries-analysis/
├── data/                # 원본 데이터 (CSV)
├── images/              # 분석 그래프 4개 (PNG)
├── analysis.ipynb       # 분석 코드 (Jupyter Notebook)
├── app.py               # 대시보드 (Streamlit, 보너스 ①)
├── REPORT.md            # 분석 리포트 (결과·인사이트·결론)
├── requirements.txt     # 사용 라이브러리 목록
└── README.md            # 이 파일
```

## 실행 방법

1. Python 3.10 이상 설치 (실제 실행 환경: Python 3.13, Windows + VS Code)
2. 필요 라이브러리 설치:
   ```
   pip install -r requirements.txt
   ```
3. `analysis.ipynb`를 열어 위에서부터 순서대로 셀을 실행

## 데이터 출처

- Open-Meteo Historical Weather API (archive-api.open-meteo.com)
- 지역: 창원 (위도 35.23, 경도 128.68)
- 라이선스: CC BY 4.0 — "Weather data by Open-Meteo.com"

## 분석 결과 요약

- 창원 기온은 8월(약 27.6°C) 최고, 1월(약 2.1°C) 최저의 뚜렷한 계절성을 보인다.
- 연평균은 2024년(15.42°C)이 가장 높았으나, 3년만으로는 일관된 추세로 보기 어렵다.
- 하루 사이 기온 급락은 11~1월에 집중되며, 겨울의 하루 평균 변동폭은 여름의 약 2.6배다.

자세한 내용은 [REPORT.md](REPORT.md)를 참고하세요.

## 📊 대시보드 (보너스 ① 분석 결과 서비스화)

기간과 이동평균 일수를 바꿔 가며 기온 흐름을 탐색할 수 있는 웹 대시보드입니다. (`app.py`)

### 실행 방법

```
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열립니다. 주소 뒤에 `?start=2024-06-01&end=2024-08-31&ma=7`처럼 붙이면 해당 조건으로 바로 열립니다.

### 화면 구성

- **왼쪽 사이드바**: 기간 선택, 이동평균 기간(7·14·30·60일) 선택
- **요약 카드**: 선택 기간의 평균기온, 가장 더운 날, 가장 추운 날, 하루 최대 하락
- **그래프**: 일별 평균기온 + 이동평균선, 연-월별 평균기온 막대그래프
- **표**: 하루 사이 기온이 가장 크게 떨어진 날 TOP 5

### 기간/조건 변경 시나리오

**① 전체 기간 (2023-01-01 ~ 2025-12-31, 30일 이동평균)**
30일 이동평균선이 매년 여름에 오르고 겨울에 내려가는 계절 패턴이 3번 반복된다. 하루 최대 하락은 2023-11-24(−10.0°C)이다.

![전체 기간](images/05_대시보드_전체.png)

**② 2024년 여름으로 좁히기 (2024-06-01 ~ 2024-08-31)**
평균 25.6°C, 가장 더운 날은 2024-08-03(30.1°C)이다. 하루 최대 하락이 −3.6°C에 그쳐 여름은 기온이 안정적이다.

![2024년 여름](images/06_대시보드_여름.png)

**③ 같은 여름, 이동평균을 7일로 바꾸기**
7일 이동평균은 일별 기온을 더 가깝게 따라가며 짧은 더위·주춤함이 드러나고, 30일은 큰 흐름만 남긴다. 목적에 따라 평균 기간을 골라야 함을 확인할 수 있다.

![7일 이동평균](images/07_대시보드_7일.png)

**④ 겨울로 바꾸기 (2023-12-01 ~ 2024-02-29)**
평균 4.5°C, 하루 최대 하락 −9.9°C(2023-12-16)로 여름보다 일간 변동이 훨씬 크다. 일별 선이 약 −6°C~16°C 사이를 크게 오르내린다. → REPORT.md 인사이트 3(급변은 겨울에 집중)을 대시보드로도 확인할 수 있다.

![2023~24 겨울](images/08_대시보드_겨울.png)
